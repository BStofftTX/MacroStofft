# Security Policy

## Reporting a security concern

Use GitHub's private vulnerability reporting feature for this repository or the directly affected project repository. Do not disclose exploitable details in a public issue.

Include:

- the affected repository, page, component, and commit
- safe reproduction steps
- the potential impact
- any suggested mitigation

## Sensitive information

Do not commit or post credentials, API keys, private business documents, customer information, personal data, protected health information, proprietary datasets, or internal agent configuration.

Public repositories are portfolio and research surfaces; they are not approved storage locations for confidential operational material.
