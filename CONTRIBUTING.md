# Contributing

This repository is MacroStofft's public company and engineering-portfolio overview.

## Appropriate contributions

- corrections to broken links or factual errors
- clearer descriptions of public repository capabilities
- accessibility and documentation improvements
- proposals tied to a specific public engineering project

## Before opening a change

1. Search existing issues first.
2. Reference an issue for substantive changes.
3. Verify claims against the linked public repository.
4. Do not add customer names, private business information, credentials, pricing, personal data, or unpublished project material.
5. Direct project-specific code changes to the relevant project repository.

Use focused branches and meaningful commits. Do not manufacture activity, backdate work, or split trivial changes for contribution counts.
